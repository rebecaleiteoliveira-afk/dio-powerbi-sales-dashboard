# 📊 Dashboard de Vendas e Rentabilidade - Power BI

Projeto prático desenvolvido durante a formação de Power BI na plataforma DIO. O objetivo consistiu em construir uma visão analítica sobre o conjunto de dados `Financial Sample`, detalhando volume comercializado, faturamento e margens de lucro por país e segmento de mercado.

---

## 🚀 Estrutura do Dashboard

O relatório conta com uma abordagem visual executiva composta pelos seguintes recursos:

* **Volume de Vendas por País:** Mapa de dispersão geográfica com bolhas dimensionadas pelo volume total faturado (`Sales`) e detalhes contextuais nas dicas de ferramenta (`Units Sold`).
* **Distribuição de Lucro por País:** Visualização geográfica focada na geração líquida de caixa (`Profit`), permitindo identificar discrepâncias entre regiões de alto faturamento e real rentabilidade.
* **Margem de Lucro por Segmento:** Gráfico circular detalhado com rótulos de dados diretos (categoria e percentual), facilitando a identificação imediata dos segmentos mais lucrativos (`Government`, `Small Business`, `Channel Partners`, etc.).
* **Interatividade Dinâmica:** Filtragem cruzada nativa habilitada entre todos os visuais do relatório.
